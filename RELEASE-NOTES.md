# Билеты 0.50.0

- В меню выбранного показа добавлено «Редактировать показ»: название и время. Дата, зал, места, выдачи и сохранённые документы сохраняются. Архивные показы недоступны для изменения.
- Ticket PRO сохраняет логин и пароль защищённо для текущего пользователя Windows и автоматически восстанавливает вход после окончания сессии. Для первоначального сохранения данных нужно один раз войти в этой версии. При неверном пароле повторные автоматические попытки прекращаются до успешного входа.
- На цветных кнопках цен — белый шрифт с чёрной обводкой и тёмной тенью. Размеры кнопок, размер шрифта и цвета фона сохранены.
- Ускорено снятие подсветки статусов и цен: готовая схема используется повторно, легенда не перестраивается и база повторно не читается ради подсветки.
