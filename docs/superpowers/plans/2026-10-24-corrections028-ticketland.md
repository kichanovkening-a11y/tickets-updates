# Последние правки и автоматическое подключение Ticketland

**Разрешение:** пользователь «давай с учетом последних моих правок и подключим тикетленд», «делай»; уточнил, что программа сама входит и получает отчёт.

**Подход:** существующий WPF/SQLite. Проверенный отчёт Ticketland, автоматический вход из программы и получение данных без ручной выгрузки; конкретный транспорт определяется проверкой реального отчёта. Не переносить секреты из браузера. Не менять другие утверждённые элементы.

- [x] Флажок «Выдача №…»: красный фон, белый текст во всех документах.
- [x] Подтверждение перед фактической повторной печатью; «Нет» ничего не печатает. Первая печать без этого предупреждения.
- [x] Щелчок по пустому месту закрывает развёрнутые возвраты журнала и истории получателя.
- [x] «Расценовка» и «Дата» по центру своих полей; начальный фокус и курсор в дате при открытии формы.
- [x] Найти и исправить причину повторного появления удалённого зала; сохранить историю.
- [x] Проверить авторизацию, получение отчёта с сектором/рядом/местом и полноту продаж. Реализовать автоматический вход/загрузку в программе, защиту от двойного назначения, сохранение последнего успешного результата при ошибке.
- [x] Проверки затронутых функций, затем одна полная проверка Windows перед выпуском; исправления/новые проверки только по выявленным сбоям.

## Проверено до Windows-выпуска

- 32/32 затронутых проверки Core; приложение и UI-проверки скомпилированы.
- Прямой отчёт Ticketland за октябрь: 767 записей / 46 показов; число записей парсера совпало с DOM.
- REST-параметры фактического отчёта: BD и ED, DateTime, подсказки «С»/«По».
- Сверенные возвращённые места, включая частичный возврат, отсутствовали в текущем списке продаж.
- Автоматический HTTP-вход проверен моделируемой сетью; секреты браузера не переносились в программу. Для первого подключения на каждом компьютере нужен вход через настройки приложения.
- Полный период в браузере оказался тяжёлым для отображения; клиент получает исходный HTML без отображения с ограничениями 20 МБ / 90 секунд. При ошибке предыдущий отчёт сохраняется.
