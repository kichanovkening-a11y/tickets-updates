БИЛЕТЫ — тестовая версия 0.5.0

ЗАПУСК
1. Распакуйте весь архив в папку на компьютере или флешке.
2. Откройте Tickets.exe в корне папки программы. Не запускайте из окна ZIP.
3. Windows 10/11, 64 бита. Интернет для работы не нужен.

ПЕРВАЯ ПРОВЕРКА
При запуске открывается главная страница без выбранного спектакля. Кнопка «Главная» возвращает на неё.
Вверху справа есть отдельные кнопки «Свернуть», «В окно»/«Развернуть» и «Закрыть».
Выберите мероприятие слева. В базе сохранены старые даты — поиск работает по названию, площадке и дате.
Нажмите на свободные цветные места, введите получателя и нажмите «Выдать выбранные».
Для тестов по умолчанию используется серия ТЕСТ. Первый номер можно изменить.
Серия и номер не повторяются, включая ранее возвращённые билеты. Нумерация общая для всех мероприятий внутри серии.
Для возврата выберите выданные серые места и нажмите кнопку возврата, либо откройте выдачу в журнале и выберите билеты в накладной.
Закройте программу и снова откройте: выдача и возврат должны сохраниться.

СХЕМА
Колесо мыши — масштаб. Правая или средняя кнопка с перетаскиванием — сдвиг.
Левая кнопка — выбрать/снять место. Протянуть левой кнопкой — добавить группу мест к уже выбранным.
«Весь зал» — вписать схему в окно. «Снять выделение» — очистить выбор.
Цвет обозначает цену, серый с белой отметкой — выдано, светло-серый — цена не назначена.
Выдать можно только свободные места с назначенной ценой.

ДАННЫЕ
Использована одна исходная база 2619_tickets.mdb. Старые выдачи исключены по вашему указанию.
Перенесено: 16 площадок, 59 секторов, 11 925 зрительских мест, 626 показов.
Программа создаёт Data/tickets.db при первом запуске. Все новые операции сохраняются туда сразу.
Data/seed.db — исходная тестовая база; при обычных запусках рабочая база из неё не перезаписывается.
Backups — автоматическая копия при первом запуске за день. Кнопка «Резервная копия…» сохраняет копию в выбранное место.
Закрывайте программу перед извлечением флешки.

СОСТАВ ЭТАПА
Есть: выбор мероприятия, реальные схемы, поиск, цены, масштаб, групповое выделение, выдача, возвраты, журнал, резервные копии.
Теперь доступны: создание залов и копий существующих залов; каталог спектаклей; создание расценовок (из выбранных мест, всего зала, старой расценовки или существующего показа); создание нового показа с датой и временем. Кнопки находятся слева и на главной странице.
Порядок: Создать зал → Создать спектакль → Создать расценовку → Создать показ.
Накладная открывается после выдачи или нажатием строки журнала. Доступны сохранение в Word и печать. «Выдать и распечатать» сначала сохраняет выдачу, затем открывает диалог печати.
Перед выдачей можно применить новую цену к выбранным местам. Исходная расценовка остаётся прежней.
Редактор печатных макетов пока не реализован.
Исходный код: github.com/kichanovkening-a11y/tickets-updates.

ПРОВЕРКА СБОРКИ
Сборка Windows x64 с включённым runtime .NET 8.0.32 завершена.
Интеграционные тесты учёта на SQLite пройдены.
Проверяются запуск окна на Windows, работа редакторов и подготовка страниц накладной к печати. Физическая печать проверяется на вашем принтере.

ОБНОВЛЕНИЕ ЧЕРЕЗ GITHUB
В верхней панели — кнопка «Обновление». Источник: kichanovkening-a11y/tickets-updates.
Проверка и скачивание требуют интернет. Обычная работа программы — без интернета.
Пакеты обновления не включают Data, Backups и пользовательские документы. Перед установкой сохраняется копия базы. Скачиваются только изменившиеся компоненты.
При первом запуске распакуйте всю папку Tickets и откройте Tickets.exe. Перед извлечением флешки закрывайте программу.

ИНТЕРФЕЙС
Формы открываются внутри главного окна. В «Настройках» можно включить отдельные окна.
Получателя можно найти по части названия, выбрать из общего списка или ввести нового.
Нажмите название спектакля, чтобы раскрыть его показы. Ближайшие идут первыми. Прошедшие собраны под одной кнопкой «Прошедшие» и доступны для просмотра.
Время показа: часы, минуты и секунды — выбор или ручной ввод. Повторный показ на одной сцене в ту же дату и время создать нельзя.

НОВОЕ В 0.5.0
В редакторе зала задайте количество рядов и настройте места и проход в таблице каждого ряда. Первые обозначения могут быть числом, латинской или русской буквой. Выбранные на схеме места удаляются кнопкой или Del без перенумерации.
Кнопка «Изменить цену» находится над количеством и суммой выбранных мест. Для занятых мест отображается получатель.
Накладные сохраняются автоматически в Data/Documents/Накладные. В настройках меняются папка документов и отправитель по умолчанию. Отправителя конкретной накладной можно изменить в её форме. «Сохранить как…» создаёт отдельную копию.
Кнопка «Спецификации» открывает список документов организаций. Для каждой организации хранится одна редактируемая спецификация с возможностью сохранения в Word и печати.
