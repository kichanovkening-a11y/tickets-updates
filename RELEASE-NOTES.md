# Билеты 0.49.0

- Цветные кнопки цен увеличены по высоте на 5 пикселей; шрифт увеличен.
- Щелчок по пустому месту снимает подсветку выбранных цен и активное выделение кнопок. При сбросе цен выбранные места сохраняются.
- Обновлятор закрывается после подтверждённого успешного запуска новой версии. При ошибке окно с объяснением остаётся открытым.
- Кнопка обновления мигает красным во время получения мест из Ticketland и возвращается к обычному виду после завершения или ошибки.
