# Билеты 0.34.0

- Итоги Ticketland относятся только к выбранному показу: отмеченные места, несопоставленные билеты и билеты без ряда или места.
- Счётчик конфликтов и список по нажатию показывают только выбранный показ.
- «Расхождения» в настройках открываются для выбранного показа.
- При переключении показа итоги обновляются по сохранённому отчёту.

Алгоритм сопоставления, продажи, выдачи и данные залов не изменены.
