БИЛЕТЫ — тестовая версия 0.7.0

ЗАПУСК И ОБНОВЛЕНИЕ
Распакуйте всю программу в папку компьютера или флешки и запустите Tickets.exe. Windows 10/11, 64 бита. Запускайте из папки, не из окна ZIP.
Нажмите «Обновление», чтобы установить следующую версию. Рабочая база и документы находятся в Data и сохраняются при обновлениях.

КАТАЛОГ
Слева: залы, спектакли, расценовки, новый показ и получатели/организации. Поиск — по началу значимых слов, без учёта ООО, ИП, АНО и «Театр», регистра и ё/е.
Спектакль раскрывает ближайшие показы. Прошедшие доступны в серой группе. Встроенные формы можно переключить на отдельные окна в настройках.
Для нового показа выберите спектакль, площадку и расценовку, дату и время с секундами. Дубли одной площадки и времени запрещены.
Удаление из справочников сохраняет выдачи, историю и документы. Удалённые показы доступны в группе «Удалённые из справочников»; для них разрешены просмотр и возврат на схеме. В организациях включите «Показать удалённых» для доступа к их истории.

ЗАЛ И РАСЦЕНОВКИ
Числовые или буквенные обозначения рядов и мест. После ввода количества рядов настройте места и проходы по каждому ряду. Удаление мест со схемы сохраняет номера и координаты остальных. Зал сохраняется новой копией.
Расценовки площадки можно копировать и редактировать. Шаблон другой площадки переносит цены для совпадающих сектора, ряда и места. Сохранение — под новым названием.
Яркий цвет закреплён за ценой для всех схем. Для новой цены выбирается свободный цвет с образцом. «Шаг назад» отменяет последнее изменение в редакторах и изменение цены показа.

ВЫДАЧА И ВОЗВРАТ
Клик выбирает место, повторный клик снимает его; протягивание левой кнопкой добавляет группу мест. Колесо меняет масштаб, правая или средняя кнопка двигает схему.
«Изменить цену» сохраняет цену непосредственно в показе. После применения выделение снимается: выберите места для выдачи снова.
Выберите получателя и нажмите «Выдать выбранные». Откроется накладная. Печать выбирается в ней вручную. Номер присваивается при выдаче; просмотр и повторная печать его не меняют.
Для возврата выберите выданные места на схеме. В накладной панели возврата нет. История возвращённых билетов сохраняется.
Журнал показывает выдачи текущего мероприятия. Справочник организаций — все выдачи выбранного получателя.

ДОКУМЕНТЫ
В накладной: договор, акт, ТТН, счёт и спецификация. Первые четыре документа готовятся автоматически для текущего получателя. Спецификация сохраняется одна на организацию.
«Сохранить» записывает документ в базу и Word. «Изменить текст / шаблон» позволяет редактировать документ выдачи; «Сохранить шаблон» использует текст в следующих выдачах с автоматической подстановкой получателя.
Текст по умолчанию — пример для замены вашим. Шаблон выдачи сохраняется отдельно: изменение общего шаблона не переписывает старые выдачи.
Отправитель по умолчанию ООО "Альянс ТА", в накладной — выбор из сохранённых или ручной ввод. В настройках меняются отправитель по умолчанию и папка документов (обычно Data/Documents).
Все итоги содержат строку с цифрами и жирную строку «Итого» с количеством и суммой цифрами и прописью.

TICKETLAND
Автоматический импорт подтверждённых продаж пока не подключён. Недоступные, забронированные и закрытые для продажи места автоматически проданными не считаются.
