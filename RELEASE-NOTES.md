# 0.21.0

- Новый показ открывается с пустыми полями; зал, спектакль, расценовку, дату и время выбирает пользователь.
- Исправлены сохранение новой расценовки с прежними ценами и новым названием, проверка мест без цены и компактная строка итогов.
- «Заблокировать» / «Разблокировать» вместо снятия с продажи; для разблокировки мест без цены требуется назначить цену.
- Левая кнопка выбирает и снимает места, правая открывает действия. Занятые группы доступны для возврата, смешанный выбор оставляет свободные.
- Ширина столбцов журнала сохраняется в пикселях отдельно для каждого мероприятия, включая перетаскивание границы заголовка.
- Исправлены компактность и выравнивание кнопок получателей и отправителей; значения полей центрированы. Удалённый отправитель не мешает выбрать действующего или создать нового.
- Исправлена структура объединённых ячеек ТТН и создание свежей копии Word. Печать из просмотра документа направлена в предварительный просмотр приложения.
- Номер и дата договора сохраняются автоматически. Представитель и должность находятся в реквизитах получателя и обновляют комплект автоматически. Площадка берётся из мероприятия во всех документах.
- Зал открывается нажатием строки без отдельной кнопки. Экстрим партер исключён из рабочих схем «Русская песня»; история сохранена, прежний скан не использован.
- Создание зала: таблица рядов рядом со схемой, живой предварительный просмотр, исправлена ошибка Refresh во время редактирования.
- Добавлен пробный импорт контуров кресел со скана с наложением и обязательной ручной проверкой каждого ряда и места. Это не автоматическое распознавание номеров; неполные схемы нужно дополнить и проверить.

Ticketland не изменён. Реальное открытие документов в установленном Microsoft Word не заменяется проверкой XML; требуется пользовательская проверка ТТН после обновления.
