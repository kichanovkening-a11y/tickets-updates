# Изменения 0.33 — план и согласованный формат

Пользователь поручил выполнить известные правки и дать зал для испытания.

- Один импорт в Настройках определяет тип по внутренним Format/Version/Kind, а не имени файла.
- Экспорт выбранного зала, спектакля, расценовки или бланка. Переносим только выбранные данные и необходимые зависимости. Выдачи, организации, доступ Ticketland и база целиком не экспортируются.
- Импорт зала всегда добавляет новую схему; при совпадении имени показываем предупреждение и предлагаем копию или отмену. Рабочая схема и выдачи не перезаписываются.
- Расценовка переносится вместе с залом, с локальным переназначением идентификаторов мест. Бланк со сканом переносит изображение, а не путь чужого компьютера.
- Ошибки формата/версии, неполные данные, повторные места и некорректная геометрия отклоняются до изменений.
- Ticketland: понятные общие счётчики и список конфликтов по нажатию; точная причина несовпадения места. Продажи и алгоритм сопоставления не меняются.
- Фото в Партнёрах — отдельный проект: сюда не включается. Резервное копирование в облако по-прежнему отложено.

## Порядок
1. Проверки переноса зала, распознавания, дублей и испорченных файлов: RED, реализация, GREEN.
2. UI импорта/экспорта и проверки Windows.
3. Счётчики и конфликты Ticketland; проверки сохранности выдач и точных причин.
4. Сборка Windows 0.33, проверка запуска, публикация; настоящий экспорт зала для испытания на отдельной базе.

## Проверки риска
Переименование файла, чужой формат, новые версии, повреждённые поля, одинаковые имена, скрытые места, проходы, повёрнутые подписи, сохранение рабочих выдач. Проверяем затронутые модули, не всю программу (прямое требование пользователя).

## Результаты и решения
- Transfer033: RED (отсутствующие методы), GREEN 5/5; расширенные проверки и конфликты 9/9.
- Диагностика отсутствующего места: RED «missing seat remains ambiguous», GREEN.
- Независимый review033: исправлены три важных замечания — сохранность глобальной палитры, обязательные поля формата/мест, доступность конфликтов по кешу и обновление после местных действий.
- Цвета импорта: существующие цвета принимающей базы сохраняются; для нового номинала с занятым цветом выбирается свободный.
- Никакая геометрия действующего зала не исправляется автоматически. У несуществующего места показывается точная причина.
- Регрессия Ticketland 032: 60/60, без изменения сопоставления.
- Сборка WPF проходит; существующее предупреждение nullable в Journal016Checks.cs не относится к изменённым файлам.
