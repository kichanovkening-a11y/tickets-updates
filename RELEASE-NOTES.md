# Билеты 0.39.0

- Исправлена загрузка Ticket PRO после входа: список активных мероприятий может открываться по адресу `/management/show/active`. Программа теперь распознаёт этот адрес и продолжает автоматический поиск сеансов вместо ошибки «список сеансов не загрузился полностью».
- Сессия Ticket PRO сохраняется между запусками в зашифрованном виде для текущей учётной записи Windows. Пароль для этого не сохраняется. Если сервер завершил сессию, потребуется повторный вход.
- Учётная сессия остаётся на этом компьютере и не включается в переносимую базу или её резервные копии.
