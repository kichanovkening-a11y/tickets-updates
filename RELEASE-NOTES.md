# Билеты 0.28.1

- Ticketland: убрана загрузка истории продаж с 2000 года. Получаем проданные места по датам текущих сеансов — от сегодняшнего дня до последнего действующего показа в программе.
- Используется отчёт по периоду мероприятий; дата покупки билета не ограничивает загрузку. Возвращённые билеты исключаются, в том числе при частичном возврате стоимости.
- Вход и загрузка отчёта показываются отдельно. Ошибка сообщает, на каком этапе остановилось подключение; автоматическое обновление сохраняет это сообщение и последние успешные данные.
- Исправлена привязка билетов на продолжениях страниц старого отчёта: текст колонтитула больше не принимается за название сеанса. Переход на новый отчёт исправляет такие записи без изменения мест и стоимости.
- Если текущих сеансов нет, проверяется только вход, без загрузки истории.
- Исправлено сохранение названия и адреса существующего зала: сохраняется сам зал, без создания лишней копии. Удалённые залы остаются удалёнными. Изменение мест и схемы по-прежнему требует нового названия.
