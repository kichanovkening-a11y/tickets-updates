# Билеты 0.41.0

- Ticket PRO обновляет только открытый показ: при его выборе, по кнопке «Обновить» и каждые 5 минут. Полный обход всех показов при запуске и обычном обновлении убран.
- При переходе к другому показу прежнее чтение отменяется. Быстрые переключения не накапливают очередь; повторные запросы одного показа объединяются.
- Сохранённая связь открывает нужную схему напрямую. Если связи ещё нет, поиск ограничен спектаклем выбранного показа.
- Исправлены названия источника в настройках, легенде, статусах мест, подсказках, окне конфликтов и сообщениях печати/подтверждения брони. Данные Ticket PRO подписываются как Ticket PRO; сохранённые отчёты Ticketland сохраняют своё название.
- Удалены кнопки «Весь зал», «−» и «+» на схеме показа.
- Вместо текстовой кнопки раскрытия зала добавлен зелёный значок с четырьмя стрелками справа над «Обновить», за пределами схемы. Повторное нажатие возвращает обычный вид с левым меню.
