# Билеты 0.37.0

- Подключение схем Ticket PRO: точные места со статусами «Продано», «Занято» и «В продаже». В настройках Ticketland выберите местный показ, войдите в Ticket PRO, откройте управление билетами нужного сеанса и нажмите «Подключить этот сеанс».
- Подключённые сеансы обновляются при запуске и каждые пять минут. Сессия хранится на этом компьютере; при её окончании нужен повторный вход. Последние данные и время обновления сохраняются при ошибке.
- Занятые непроданные места освобождаются через правую кнопку только в программе. Продажа в Ticket PRO снова блокирует выдачу и печать. Базис и Ticketland не изменяются.
- Зал при выдаче занимает ширину окна, правая панель билетов стала уже и регулируется разделителем. Расценовка открывается на весь экран с панелью справа.
- Убрана отдельная кнопка бронирования; действия доступны правой кнопкой.
- Поле даты принимает нажатие по всей площади и показывает курсор ввода.

Для подключения используется Microsoft Edge WebView2 Runtime, уже установленный в Windows 11. Учётная сессия не переносится на флешку и не включается в резервные копии базы.
