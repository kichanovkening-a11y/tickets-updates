Версия 0.8.0

Создание зала: настройки разделены на вкладки, таблица рядов получила отдельную большую область. Кнопки добавления сектора и сохранения всегда видны. При сохранении пустой новой схемы первый сектор строится по заполненным настройкам.

Смешанные подписи рядов и мест: «А, 1» создаёт А, 1, 2… Начало нумерации мест можно задать отдельно для каждого ряда; обратная нумерация и удаление без перенумерации сохраняются.

Длинные надписи автоматически уменьшаются, чтобы помещаться в кнопки прежнего размера.

«Расценовки» открывают список площадок. Выбор площадки раскрывает только её расценовки. Переключатель «Расценовки всех площадок» убран.

«Спектакли» раскрывают показы: ближайшие по порядку, прошедшие — отдельной серой группой. Нажатие на показ открывает схему. Через правую кнопку на спектакле можно добавить даты.

В создании показа можно добавить несколько дат со своим временем, включая секунды. Весь набор сохраняется одной операцией: дубли дат и конфликты сцен отклоняются без частичного создания.

Удаление получателей, спектаклей, площадок и расценовок — через правую кнопку с подтверждением. Отдельные кнопки удаления убраны, история выдач и документы сохраняются.

Загрузка конкретных проданных мест Ticketland в этой версии не подключена.
