# Билеты 0.38.0

- Ticket PRO: после входа программа автоматически находит показы по названию, дате, времени и площадке. Выбирать и подключать каждый сеанс вручную больше не нужно.
- Исправлена причина, по которой после входа могли оставаться данные старого отчёта, включая приглашения среди продаж. Полная схема Ticket PRO заменяет старые отметки: приглашения относятся к «Занято».
- Если конкретный показ ещё не обновлён, программа прямо сообщает об этом. Ошибка или тайм-аут одного сеанса не мешает обновить остальные; последние успешные состояния сохраняются.
- Добавлена кнопка «Раскрыть зал / Свернуть зал»: раскрытие скрывает левое меню, сворачивание возвращает его. Правая панель билетов и кнопка переключения доступны в обоих режимах. Кнопки масштаба «+ / −» сохранены.
- В расценовке также можно раскрыть зал и вернуть обычный размер, в том числе при открытии формы внутри главного окна.
- Сохранены обновление каждые пять минут, локальное освобождение занятых непроданных мест, действия правой кнопкой и ввод даты по всей площади поля. Внешние билеты и настройки Ticketland не изменяются.

Для подключения используется Microsoft Edge WebView2 Runtime, уже установленный в Windows 11. Учётная сессия не переносится на флешку и не включается в резервные копии базы.
