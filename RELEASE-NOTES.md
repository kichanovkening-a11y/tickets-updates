# Билеты 0.51.0

- На главной странице — афиши из активного репертуара VIP-Театра, по пять в ряд. Левый щелчок открывает активные даты спектакля, выбор даты открывает зал.
- Карточки можно переставлять мышью. Правая кнопка открывает команды «Добавить дату» и «Удалить с главного экрана». Скрытые карточки возвращаются кнопкой «Добавить спектакль».
- При создании спектакля можно выбрать соответствующую афишу сайта или сохранить спектакль без афиши. У существующего спектакля привязка доступна в справочнике. Картинки сохраняются рядом с базой для работы без интернета.
- На цветных кнопках выдачи и расценовки цены отображаются чёрным шрифтом с группировкой тысяч, например **50 000 × 30 = 1 500 000**.
