# Билеты 0.45.0

- В редакторе документов работают Enter, Shift+Enter и вставка текста с переносами. Пустые строки сохраняются; автоматические поля `avto` защищены.
- При установленном Microsoft Word документы показываются и печатаются по одному макету Word, с его страницами, полями и шрифтами. Без Word остаётся просмотр с явным указанием возможных различий в переносах.
- Последний пункт договора связан с реквизитами и подписями. Размер шрифта не уменьшается. Если весь заключительный блок физически не помещается на лист, программа объясняет причину перед печатью.
- Формы сохраняются отдельно для каждого получателя, включая накладную. В новых общих комплектах шаблон с `avto` хранится отдельно от заполненного документа. Ранее сохранённые комплекты и архив остаются самостоятельными документами.
- ТТН построена по присланной форме ТОРГ-12: две стороны A4 в альбомной ориентации, исходная сетка, поля и шрифты. Убраны добавленные строка мероприятия и отдельный блок подписей; данные заполняются внутри исходных ячеек. Для большого числа цен добавляются страницы продолжения.
- В печатном просмотре документов убраны «Отмена» и «Обновить просмотр». Кнопка печати находится в строке настроек; изменения полей автоматически обновляют страницы.

Получение мест, авторизация, отчёт и обновление данных Ticket PRO не изменены.
