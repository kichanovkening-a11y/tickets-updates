# Билеты 0.47.0

- ТТН по исходной форме: альбомные страницы, исходная сетка и оформление, полные реквизиты плательщика. Просмотр и печать используют один макет Excel; сохранение утверждённой формы — XLSX.
- Сохранённый текст в полях утверждённой ТТН переносится в соответствующие ячейки Excel. Исторические нестандартные документы сохраняют исходный формат.
- Повторное открытие документов использует готовые страницы. Новые документы используют уже запущенный отдельный процесс Word/Excel.
- Закрытие документа закрывает весь комплект одним нажатием, без повторного появления накладной.
- Щелчок в поле получателя раскрывает полный список; ручной ввод нового получателя сохранён.
- Архивные показы доступны для просмотра зала, журнала и сохранённых документов с печатью. Изменения и удаление запрещены. Комплект с несколькими датами остаётся активным до архивации всех показов.
- В настройке форм получателя тип документа сначала не выбран; загрузка доступна после выбора.
- Ticket PRO, его отчёт и получение мест не изменены.

Для точного просмотра и печати обычных документов используется установленный Microsoft Word, для утверждённой ТТН — Microsoft Excel. Сохранение XLSX не требует запуска Excel.
